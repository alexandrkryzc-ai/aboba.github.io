# Тренажёр «1С:Профессионал» — Платформа 8.3

Статический веб-тренажёр для подготовки к сертификации **1С:Профессионал по платформе** (1С:Предприятие 8.3).

## Содержимое

- **961 вопрос** по 14 разделам
- **78 вопросов с картинками** (91 изображение)
- Пояснения и ссылки на ITS
- Режимы:
  - Тренировка по разделам
  - Случайный билет (14 вопросов, 30 мин, порог 12/14)
  - Работа над ошибками
  - Поиск по тексту вопросов
- Статистика и прогресс в localStorage

## Как запустить

1. Распакуйте архив
2. Откройте `index.html` в браузере  
   (или разместите папку на любом статическом хостинге / GitHub Pages)

## Структура

```
platform-trainer/
├── index.html      # интерфейс
├── app.js          # логика
├── data.js         # банк вопросов (961)
├── images/         # скриншоты к вопросам
└── README.md
```

## Обновление репозитория

Замените содержимое вашего репозитория `aboba.github.io` файлами из этой папки (или создайте новый репозиторий).

Готово к использованию.
